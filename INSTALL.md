# Installing TextureSplitter

A simple guide for installing and opening TextureSplitter — no technical
knowledge required.

## What you need

| | Mac | Windows |
|---|---|---|
| Operating system | macOS 11 (Big Sur) or newer | Windows 10 or newer (64-bit) |
| Free disk space | ~150 MB | ~150 MB |
| Internet connection | Only to download the app | Only to download the app |

You do **not** need to install Python or anything else — the app runs on its
own.

---

## Installing on Mac

1. **Download** the file you were given (it will be named something like
   `TextureSplitter.app` or `TextureSplitter.zip`).
2. If it's a `.zip` file, **double-click it** to unzip it. You'll get a file
   named `TextureSplitter.app`.
3. **Drag `TextureSplitter.app` into your `Applications` folder.** (You can
   skip this step and run it from anywhere, but moving it to Applications
   keeps things tidy.)
4. **The first time you open it**, macOS will likely refuse and show a
   warning like *"TextureSplitter cannot be opened because it is from an
   unidentified developer"* or *"Apple could not verify..."*. This is normal
   for apps that aren't distributed through the App Store — here's how to
   get past it:
   - **Right-click** (or hold `Control` and click) on `TextureSplitter.app`.
   - Choose **Open** from the menu.
   - A dialog will pop up warning you again — click **Open** on that dialog
     as well.
   - If you don't see an **Open** button, go to  **System Settings → Privacy
     & Security**, scroll down, and click **Open Anyway** next to the
     mention of TextureSplitter, then confirm.
5. From now on, you can just **double-click** the app normally to open it.

## Installing on Windows

1. **Download** the file you were given (e.g. `TextureSplitter.exe` or
   `TextureSplitter.zip`).
2. If it's a `.zip` file, **right-click it** and choose **Extract All...**,
   then open the extracted folder.
3. **Double-click `TextureSplitter.exe`** to run it.
4. Windows will likely show a blue screen titled **"Windows protected your
   PC"** (this is Windows SmartScreen — it appears for any app that isn't
   digitally signed by a large company, it doesn't mean the app is unsafe).
   To continue:
   - Click **More info**.
   - Click the **Run anyway** button that appears.
5. The app will open. You can keep the folder wherever you like (e.g. your
   Desktop) and double-click the `.exe` any time to run it — there's nothing
   else to install.

---

## Using the app

1. Click the button to **choose a JSON file** (the matching PNG spritesheet
   is found automatically next to it).
2. Pick a **sprite size** from the dropdown (or enter a custom one).
3. Choose an **output folder** — this is where the split images will be
   saved.
4. Click **CUT IMAGES**.

You can change the interface language using the button in the top-right
corner of the window.

## Uninstalling

- **Mac**: drag `TextureSplitter.app` from `Applications` to the Trash.
- **Windows**: delete the `TextureSplitter.exe` file (and its folder, if you
  extracted it from a zip).

No other files are installed on your computer — there's nothing left behind
to clean up.
